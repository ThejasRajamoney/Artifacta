Security

Files Remain Local

Artifacta performs all analysis on your local machine. No file you open, drop, or analyze is ever transmitted to an external server. Your artifacts stay on your device.

No Execution

Artifacta does not execute, run, or launch any analyzed artifact. Analysis is strictly static: it reads file structure and metadata without triggering any code.

Static Analysis Limitations

Static analysis examines a file without executing it. This approach has inherent limitations:

  • Packed or encrypted code may not be fully visible
  • Runtime behavior cannot be observed statically
  • Some techniques require dynamic analysis to detect

Artifacta focuses on what it can observe: PE structure, imports, resources, Authenticode signatures, and YARA rule matches.

Artifacta is not an antivirus. It performs static analysis to help you understand executables. It does not detect, block, or remove malware.

Telemetry Policy

Artifacta does not collect telemetry by default. No usage data, analytics, or telemetry of any kind is sent from the application.

Network Policy

During analysis, Artifacta makes no network connections. The only network activity is for downloading YARA rules you explicitly configure and checking for updates if you opt in.

Vulnerability Reporting

If you discover a security vulnerability, please report it through GitHub private vulnerability disclosure. Do not open a public issue for security vulnerabilities.

Disclaimer

Signed does not mean benign. Unsigned does not mean malicious. A digital signature proves identity, not trustworthiness.
