Release History

v1.0.0-rc.1 — Unsigned pre-release

Published for evaluation. All non-destructive qualification gates pass against the shipped binary and installer (137 Rust tests, 68-fixture corpus, 35 frontend tests, 6/6 WebView2 workflows). Stable distribution is not approved: isolated Windows install, upgrade, and uninstall qualification remains outstanding, and the installer is unsigned.

  • Evidence-driven investigation workflow
  • Static PE analysis (imports, exports, sections, resources)
  • Multi-artifact intake: ZIP, EVTX, PCAP/PCAPNG, structured logs
  • YARA-X integration for pattern matching
  • Authenticode signature inspection
  • Investigation graph visualization
  • Chronology timeline view
  • Case workflow for organizing investigations
  • JSON, HTML, PDF, CSV, and STIX reports with integrity manifests

v1.0.0-rc.1 must not be presented as a stable release until the qualification report grants distribution approval.
